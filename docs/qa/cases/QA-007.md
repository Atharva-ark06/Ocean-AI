# QA 007: dataset provenance

## Purpose
Review dataset provenance in the Ocean AI synthetic-data demonstration.

## Preconditions
Use the modernization branch and only synthetic fixtures.

## Acceptance criteria
1. The dataset provenance behavior is deterministic and documented.
2. Invalid inputs fail safely without exposing credentials or internal state.
3. Outputs preserve explicit synthetic-data provenance.
4. Record expected and actual outcomes during manual verification.

This is a review specification, not a claim that the test has passed.
